
# Distance Calculator

## Description
This code is used to calculate the distance between two points, you can use it for maps and math.

## How to run
1. Open the program file in Google Colab or vs code, etc.
2. Run the program
3. Enter the values for x1, y1 x2, and y2
4. Look at the distance displayed on the screen

## Input Needed
- x1
- x2
- y1
- y2

## Sample output
Enter x1:2
Enter x2:3
Enter y1:7
Enter y2:8
The distance is :7.07
